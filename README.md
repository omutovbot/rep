# Случайное дело (Tkinter)

Простое desktop-приложение для Windows на Python + Tkinter.

## Что умеет приложение

- Открывать/сворачивать блокнот с делами.
- Принимать список дел: **каждое дело с новой строки**.
- Игнорировать пустые строки.
- Проверять ограничение: максимум **200 символов** на строку.
- Удалять дублирующиеся строки при сохранении.
- Сохранять список в `tasks.json`.
- Автоматически загружать список из `tasks.json` при следующем запуске.
- Показывать анимацию выбора случайного дела через `after()` (без потоков).
- Предлагать выбрать дело повторно.
- Очищать список дел.

## Требования

- Windows 10/11
- Python 3.10+ (обычно Tkinter уже входит в стандартную установку Python)

## Запуск в Windows PowerShell

1. Откройте PowerShell в папке проекта.
2. (Опционально) Проверьте версию Python:

```powershell
python --version
```

3. Запустите приложение:

```powershell
python .\app.py
```

## Файлы проекта

- `app.py` — основная логика и интерфейс приложения.
- `tasks.json` — локальное хранилище списка дел (JSON).
